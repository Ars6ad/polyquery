Here are two Python functions to calculate the Fibonacci sequence: one using recursion and one using iteration.

Recursive Approach

def fib_recursive(n):
  if n <= 1:
    return n
  else:
    return fib_recursive(n-1) + fib_recursive(n-2)

Iterative Approach

def fib_iterative(n):
  a, b = 0, 1
  for _ in range(n):
    a, b = b, a + b
  return a

Complexity Analysis

  • Recursive: O(2^n) time complexity due to repeated calculations. O(n) space complexity for the call stack.
  • Iterative: O(n) time complexity. O(1) space complexity.

The iterative approach is significantly more efficient for large 'n'.
